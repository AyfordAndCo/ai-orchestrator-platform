# Task completion checklist

Use this checklist before invoking `progress-tracker.md`.

## Implementation

- [ ] Assigned issue and acceptance criteria were read.
- [ ] Changes are limited to the assigned scope.
- [ ] Tests or other appropriate regression coverage were added or verified.
- [ ] No protected branch was changed directly.

## Validation

- [ ] Required validation commands passed.
- [ ] `git diff --check` passed.
- [ ] Security, review, and workflow gates required by the issue were checked.
- [ ] Failures, skipped checks, and known limitations are recorded.

## Delivery

- [ ] `TASKS.md` reflects only evidenced completion.
- [ ] Architecture/decision documentation is updated if the design changed.
- [ ] Branch, commit SHA, and PR/base-branch details are recorded when available.
- [ ] Linear issue status and evidence comment are reconciled when connected.
- [ ] A dated entry was appended to `.agents/progress-log.md`.
